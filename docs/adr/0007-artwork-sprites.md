# Artwork sprites, not classic box sprites

Classic `b_` sprites scale poorly. We use Original PKHeX's artwork (`a_`) set everywhere, with the same overlays the artwork builder applies, and we copy box wallpapers the same way. This is a deliberate visual exception to matching Original PKHeX's default look. The files come from the Oracle, not from a private PKHeX Online pack. Compositing stays in C# and the Host only displays pixmaps.
