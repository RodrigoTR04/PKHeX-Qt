# Self-contained .NET 10, Core stays C#

.NET 10 runs on Linux and macOS. A self-contained publish puts the runtime in the app folder so the user never installs a SDK. Replacing .NET means replacing Core. NativeAOT is a second compiler mode we do not need on day one. Official Linux Releases are AppImages built by GitHub Actions on a public repo. Inside the image is the same self-contained folder: CMake for the Host, `dotnet publish` per RID for Editor layer and Core. Qt stays dynamically linked. The folder layout is kept flat so the Host still finds `dotnet/`, `lang/`, and `assets/` next to the binary.
